## 📘 Descrição do Projeto
Este projeto implementa uma **Árvore Binária de Busca (BST)** em Java, construída a partir dos dígitos do meu **RA: 2403860**.  
O objetivo é demonstrar o funcionamento da inserção ordenada, percursos e análise estrutural da árvore.

A aplicação exibe:
- 🌱 Estrutura hierárquica da árvore (em formato visual no console)
- 🌰 Raiz, folhas e altura da árvore
- 🧩 Percurso em ordem (ordenado)

---

## 🧠 Lógica de Construção
Cada dígito do RA é inserido **sequencialmente** na árvore segundo as regras:
1. Se o valor for **menor** que o nó atual → vai para a **esquerda**.  
2. Se o valor for **maior ou igual** → vai para a **direita**.
